# Agrisense Submission Evidence Template

## Project statement

Agrisense is an extension built during the Code for Communities challenge period for the Agricultural Intelligence problem statement under the Cooperation theme. It provides a farmer-facing workflow that combines local weather context, soil inputs, regenerative recommendations, and cautious AI-assisted leaf screening.

## Claims to use

Say that Vertex AI Gemini performs meaningful structured text and multimodal work and that Cloud Run is the deployment target. Say that Earth Engine, Cloud Storage, and BigQuery are implemented configured adapters: show their live status in the recording and explain any request-level failure honestly. Explain that managed voice/translation remains an optional extension.

## Claims to avoid

Do not claim a definitive crop-disease diagnosis, a pesticide prescription, a live satellite result when the value is cached, a custom-trained predictive model when none is deployed, real-world impact statistics without a measured pilot, or production readiness without a security and agronomy review.

## Final captions

Use captions such as: “AI screening aid, not a diagnosis,” “Cached demo fallback,” “Earth Engine live / cached fallback,” “Cloud Storage persistence optional,” “BigQuery telemetry non-blocking,” “Verify with a local agricultural expert,” and “State model: configurable adapter.”
