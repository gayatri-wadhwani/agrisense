06 / Data and provenance
Every signal carries its source.

Live Weather Live

Open-Meteo supplies coordinate-level temperature, rainfall, humidity, and soil-moisture context for the selected field.

Earth Engine NDVI Live / fallback

When registered and enabled, the server computes point NDVI from Sentinel-2 imagery. Otherwise, the UI labels cached context instead.

Cloud Storage Private

Leaf images can be stored in a private bucket with short-lived signed reads and an automatic demo-upload lifecycle rule.

BigQuery Telemetry

Non-identifying advisory provenance can stream to a configured table without blocking the farmer response when telemetry is unavailable.
