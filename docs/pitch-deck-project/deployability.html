09 / Deployability
Ready for the field. Built for the cloud.
01

Stateless Cloud Run Service

React + Express + tRPC keeps the farmer workflow portable, horizontally scalable, and deployable as one Google Cloud service.

02

Identity, not embedded keys

Application Default Credentials locally and a dedicated Cloud Run identity in deployment; Earth Engine JSON belongs in Secret Manager, never in the frontend.

03

Adapters with safe fallbacks

Vitest and TypeScript checks protect contracts while Earth Engine, Cloud Storage, and BigQuery report disabled or failed states without blocking the advisory.

Proposed pilot path

Validate locally

Run the complete farmer journey with Vertex AI and the deterministic fallback; confirm no secret enters the browser.

Activate one district

Register Earth Engine, create a private image bucket, and stream non-identifying provenance to BigQuery for one crop and one state model.

Expand by configuration

Add reviewed language packs, crop calendars, soil thresholds, and referral rules without rewriting the shared farmer experience.
