# Agrisense Final Pre-Submission Checklist

## 1. Source code (GitHub)

- [ ] Create a new public repository on GitHub.
- [ ] Upload the contents of the `agrisense-ai` folder (excluding `node_modules`, `.env`, and `dist`).
- [ ] Confirm `README.md`, `SETUP_LOCAL.md`, `ATTRIBUTIONS.md`, and the `docs/` folder are present.
- [ ] Add the repository link to your submission form.

## 2. Demo video (3–5 minutes)

- [ ] Use the `docs/submission-evidence-template.md` to rehearse your walkthrough.
- [ ] Show the Vertex AI success path (requires your local project configuration).
- [ ] Show the safe fallback path (disconnect Vertex or unset the provider).
- [ ] Confirm the recording distinguishes live, cached, and planned data.
- [ ] Upload to a public hosting platform (e.g., YouTube/Drive) and add the link to the form.

## 3. Pitch deck (10–12 slides)

- [ ] Review the current pitch deck artifact from the latest project checkpoint.
- [ ] Confirm it covers problem, solution, AI approach, users, deployability, and India-scale reach.
- [ ] Download as PDF/PPTX and attach to your submission.

## 4. Brief description (2–3 lines)

- [ ] Use the text in `docs/submission-brief.md`.

## 5. Deployed link

- [ ] Follow the Cloud Run deployment steps in `SETUP_LOCAL.md`.
- [ ] Verify the public URL is accessible and shows the Agrisense workspace.
- [ ] Add the live link to your submission form.

## 6. Final verification

- [ ] Confirm all compulsory rules in `docs/hack2skill-traceability.md` are addressed.
- [ ] Confirm the team registration is complete on Hack2Skill.
- [ ] Submit before the current official prototype-submission deadline (Wed 30 Sep 2026; re-check the event page immediately before submitting).
