# Third-party attributions

Agrisense is built with open-source components that remain under their respective licenses. The authoritative license text is available in each package’s metadata under `node_modules` after installation and in the package registry.

- React and React DOM: https://github.com/facebook/react
- Vite: https://github.com/vitejs/vite
- TypeScript: https://github.com/microsoft/TypeScript
- Express: https://github.com/expressjs/express
- tRPC: https://github.com/trpc/trpc
- Drizzle ORM: https://github.com/drizzle-team/drizzle-orm
- Tailwind CSS: https://github.com/tailwindlabs/tailwindcss
- Radix UI primitives: https://github.com/radix-ui/primitives
- Lucide icons: https://github.com/lucide-icons/lucide
- Google Gen AI JavaScript SDK: https://github.com/googleapis/js-genai
- Vitest: https://github.com/vitest-dev/vitest

The project does not include proprietary model weights, copied datasets, or unlicensed crop imagery. Any additional image or dataset added by the team for the final recording must include its source and license here before submission.
